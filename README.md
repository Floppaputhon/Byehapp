# Byehapp

## Telegram Business AI Assistant Bot

Бот-ассистент для Telegram Business API с AI-функциями.

### Возможности

- **Отслеживание удалённых сообщений** — текст, фото, видео, документы, голосовые, стикеры
- **AI-пересказ переписок** — краткое содержание чатов за любой период
- **Напоминания** — кому ответить, позвонить, с гибким форматом времени
- **Статистика сообщений** — кто сколько пишет, медиа, удалённые
- **Поиск по сообщениям** — полнотекстовый поиск по истории
- **Перевод текста** — AI-перевод на русский язык
- **Анализ сообщений** — тон, срочность, необходимость ответа

### Установка

```bash
cd telegram_bot
pip install -r requirements.txt
cp .env.example .env
# Заполните .env своими данными
python bot.py
```

### Настройка .env

```
BOT_TOKEN=токен_бота_от_BotFather
AI_API_KEY=ключ_от_vectorengine_ai
AI_API_URL=https://api.vectorengine.ai/v1
AI_MODEL=gpt-4o-mini
OWNER_ID=ваш_telegram_user_id
```

### Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и список функций |
| `/deleted [N]` | Показать N удалённых сообщений |
| `/summary [часы]` | AI-пересказ за N часов |
| `/remind [кому] [что] [когда]` | Установить напоминание |
| `/pending` | Кому нужно ответить |
| `/stats [часы]` | Статистика сообщений |
| `/search [запрос]` | Поиск по сообщениям |
| `/translate [текст]` | Перевод текста |
| `/analyze [текст]` | Анализ тона сообщения |
| `/myreminders` | Активные напоминания |
| `/help` | Справка |

### Как подключить Business API

1. Перейдите в **Настройки Telegram → Telegram Business → Чат-боты**
2. Добавьте вашего бота по username
3. Бот начнёт получать все сообщения из ваших чатов
