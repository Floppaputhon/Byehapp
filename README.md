# Telegram AI Assistant Bot (Business API)

Telegram-бот с AI-ассистентом для бизнес-аккаунтов, использующий VectorEngine API (Gemini 3 Flash / Claude Sonnet 4.5).

## Возможности

- **Авторизация по паролю** — доступ только для авторизованных пользователей
- **Умная модерация** — автоматическая проверка сообщений на спам, агрессию и нежелательные ссылки через AI
- **Авто-ответы** — контекстные AI-ответы на бизнес-сообщения с памятью чата (последние 20 сообщений)
- **Telegram Business API** — интеграция с бизнес-аккаунтом Telegram
- **Панель администратора** — статистика модерации, аптайм, управление настройками

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Начало работы с ботом |
| `!ответ вкл` | Включить авто-ответы (admin) |
| `!ответ выкл` | Выключить авто-ответы (admin) |
| `!status` | Панель статуса (admin) |

## Установка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Скопируйте `.env.example` в `.env` и заполните:
   ```bash
   cp .env.example .env
   ```
5. Запустите бота:
   ```bash
   python run.py
   ```

## Стек

- Python 3.10+
- python-telegram-bot 22.7
- OpenAI SDK (VectorEngine proxy)
- SQLite
